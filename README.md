# WigglyPaint

**WigglyPaint** (internet-janitor.itch.io/wigglypaint) is a fun and simple browser-based drawing tool that brings your sketches to life with animated, wobbly lines. Every stroke you make vibrates and wiggles, giving your artwork a quirky and dynamic feel.

🖌️ No need to install anything - just open your browser and start drawing!

## ✨ Features

- Animated, wiggly strokes that move as you draw https //internet-janitor.itch.io/wigglypaint
- Minimalist and intuitive interface
- Works directly in your browser
- Great for doodles, experiments, and stress-free creativity
